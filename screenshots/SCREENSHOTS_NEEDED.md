# Screenshots Needed

Capture these to bring the showcase to life. Save them into this folder using the filenames suggested below (the README already references `hero.png`).

1. **`hero.png`** ⭐ **— use as the README hero image**
   Screenshot of the IK Designs homepage hero section (the warm walnut/cream landing view with the headline and call-to-action). This is the first thing a visitor to the showcase repo sees — make it count.

2. **`order-builder-step3.png`**
   Screenshot of **Step 3 (Customise)** in the order builder — ideally showing the shape selector and material/finish swatches for a furniture item (e.g., the Sofa or Bed shape grid). This is the most visually rich and "product-y" step.

3. **`order-builder-flow.gif`**
   Short screen-recording/GIF of a user moving through two or three steps of the order builder (e.g., Step 1 → Step 2 → Step 3), showing the progress bar advancing and the transitions. Captures the guided-flow feel better than any static shot.

4. **`track-order.png`**
   Screenshot of the `/track` page after a successful lookup — showing the 8-stage progress timeline, an admin note, and at least one progress photo in the gallery.

5. **`admin-orders-list.png`**
   Screenshot of the admin Orders list view, with the search/filter controls visible and a few orders showing different status badges — demonstrates the operational tooling.

6. **`admin-analytics.png`**
   Screenshot of the admin Analytics dashboard showing the custom-built bar charts (revenue trend, top furniture, room breakdown, status distribution).

7. **`portfolio-gallery.png`**
   Screenshot of the `/portfolio` page showing the categorised gallery grid with a few real completed-project images and category filters.

8. **`mobile-order-builder.png`**
   Screenshot of the order builder on a mobile viewport (e.g., 390×844) — shows the responsive design holds up for what is likely a majority-mobile audience.

---

**Tip:** For the GIF, keep it under ~10 seconds and under 5MB so it loads quickly in the README — a tool like ScreenToGif (Windows) or Kap (Mac) works well, or screen-record and convert with ffmpeg.
